# Pipeline Leak Detection Robot 🤖💧

This project consists of the development of an open-source pipeline inspection robot designed for leak detection. It was developed as part of the **Mechatronic Systems Design** course at **UTEC**.

The system utilizes the **TETRIX®** platform for its mechanical structure and locomotion, integrating specialized sensors for identifying structural faults in industrial pipeline environments.

## 📋 Main Features
- **Platform:** Based on the TETRIX® robotics kit.
- **Purpose:** Autonomous/remote pipeline inspection.
- **Detection:** Sensor system optimized to identify pressure or humidity changes (leaks).
- **Open Source:** All mechanical design (CAD in FreeCAD) and firmware Will be available in this repository.
